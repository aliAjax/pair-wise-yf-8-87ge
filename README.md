# 胶片试映版本冻结台

在胶片分镜条核对台基础上扩展的纯前端本地应用：整理放映胶片片段、拖拽排序、统计总时长、按颜色与破损筛选、生成试映提醒，并能把连续片段冻结成试映版本。

直接打开 `index.html` 即可使用（脚本为普通脚本文件，无需构建或服务），也可以在本目录启动静态服务访问。

## 试映版本规则

- 按放映顺序选择一段**连续片段**，登记**放映室**和**版本备注**后冻结为试映版本。
- 冻结前整段校验，出现以下任一情况则**整次拒绝**，原清单和已有版本都不变：
  - 区间内任一片段标记“需跳过”；
  - 区间内有“接片松动”却没有处置备注（片段备注即处置备注）；
  - 区间内片段编号重复。
- 冻结后片段只读：不能新增、删除、移动或拖拽。
- 试映中可对冻结区间内的片段“标记新破损”：当前版本**解除冻结并完整保留版本快照**，该片段进入“待排除”状态。
- 排除该片段后，可选择新的连续区间再次冻结，版本号递增（v1、v2、…），历史快照都可展开查看。
- 版本、统计、颜色与破损筛选、试映提醒、导出全部随状态同步；导出包含当前冻结快照、当前清单（跟随筛选）和历史版本索引。
- 所有状态保存在浏览器本地存储，刷新页面后保留。

## 代码结构

业务拆成三个互不越界的模块（`js/` 下按依赖顺序加载）：

| 文件 | 职责 |
| --- | --- |
| `js/rules.js` | 规则：区间冻结校验、筛选、统计、版本快照、试映提醒（纯函数） |
| `js/store.js` | 状态与动作：冻结 / 解除冻结 / 标记破损 / 排除 / 增删排序 |
| `js/storage.js` | 本地存储：默认数据、旧数据兼容整理、localStorage 读写 |
| `js/app.js` | 界面：渲染、事件、弹窗、导出 |
