# 胶片试映版本冻结台

一个纯前端本地应用：整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、按颜色偏移与破损情况筛选、生成试映前提醒，并可把连续片段冻结成试映版本。

## 试映版本规则

- 选择连续片段区间，登记放映室与版本备注后冻结为版本。
- 区间内任一片段“需跳过”、“接片松动”却没有处置备注，或片段编号重复时：整次拒绝，原清单和版本不变。
- 冻结后区间内片段只读（不可移动、删除、排除）。
- 对片段标记新的破损会解除对应版本的冻结，并保留版本快照；排除该片段后可再次冻结。
- 版本、统计、颜色与破损筛选、提醒和导出均随状态同步刷新。

## 模块结构

- `storage.js`：本地存储模块，负责 localStorage 读写。
- `rules.js`：规则模块，冻结校验、统计、筛选、提醒等纯业务规则。
- `state.js`：状态模块，持有状态并执行变更（冻结、标记破损、排除等），变更即持久化。
- `app.js`：界面模块，负责渲染与事件接线。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。数据保存在浏览器本地，刷新后保留。
